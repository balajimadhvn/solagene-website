R for Bioinformatics & Biostatistics

R remains the language of choice for statistical analysis of biological data and hosts Bioconductor, the largest collection of genomics packages. This course combines R programming with the statistics needed to analyse experiments correctly.

Course overview

R for Bioinformatics & Biostatistics combines the R language with the statistics needed to analyse experiments correctly. It suits biologists who will analyse their own data, and anyone heading towards RNA-seq, microbiome or other Bioconductor-based work.

Statistics are taught as decisions: which test fits the design, what its assumptions are, and how multiple testing changes what a p-value means. Every analysis is written as a Quarto document, so code, results and interpretation stay together and can be re-run by anyone.

Learning outcomes

By the end of the course you will be able to:

  1. Write R code with the tidyverse
  2. Choose, run and check the right statistical test for a design
  3. Control the false discovery rate across many tests
  4. Make clear, accessible figures with ggplot2
  5. Write reproducible reports with Quarto

Practical sessions and projects

Capstone project

Reproduce a published figure

Download the data behind a published figure, reproduce it in R and write the analysis up as a reproducible Quarto report, noting any point where your result differs.

Assessed on the correctness of the analysis, the quality of the code and the reasoning in the write-up. A pass is required for the certificate.

  1. R fundamentals

    Set up an RStudio project, import a plate-reader export and compute summary statistics per condition.

  2. The tidyverse

    Reshape a wide experimental table to long format, join sample metadata and compute group-wise summaries.

  3. Statistics for biologists

    Choose and run t-tests, Wilcoxon tests, ANOVA and linear models on designed experiments, then apply Benjamini–Hochberg correction.

  4. Visualisation with ggplot2

    Rebuild a multi-panel figure from raw data with consistent scales and colour-blind-safe palettes.

  5. Bioconductor

    Load the airway dataset as a SummarizedExperiment and run a first differential analysis of treated against untreated cells.

  6. Project: a reproducible analysis report

    Reproduce a published figure from its underlying data and publish the analysis as a Quarto report with session information.
